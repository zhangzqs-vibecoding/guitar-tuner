1. 声音是什么

声音的本质是空气的振动。物体振动→挤压空气→层层传递→耳朵鼓膜振动→大脑解读为声音。

用数学描述：空气压强 P 在时间 t 的值写为 P(t)。如果 P(t) 有规律地上下波动，就是乐音；如果杂乱无章，就是噪音。

交互：改变频率，看波形 + 听声音

频率: 110 Hz (A2 弦)

关键概念：振动有规律 → 乐音。反过来，如果曲线是杂乱的锯齿、随机跳动，听起来就是噪音。吉他弦的振动天然有规律。

2. 正弦波：声音的"原子"

所有波形中最基本的是正弦波。高中数学里学过 y = sin(x)，声音里的正弦波加上时间和振幅：

\[ y(t) = A \cdot \sin(2\pi f t + \varphi) \]

公式中每个符号的物理意义：

\\(A\\)振幅波的最大高度，决定声音有多响。A 越大越响。单位是声压（任意刻度）
\\(f\\)频率每秒完整振动的次数（Hz），决定音有多高
\\(t\\)时间以秒为单位，表示"此刻"
\\(\varphi\\)相位波在 t=0 时的起始位置。两个同频同幅但相位相反的波会互相抵消！
\\(2\pi\\)弧度转换sin() 的周期是 \\(2\pi\\)，乘以 f 后周期变成 1/f 秒（即一次完整振动的时间）

为什么一定是 sin 而不是别的函数？因为 sin 描述的是自然界中最基本的周期性运动——弹簧振动、钟摆、弦振动，统统是正弦运动。这不是巧合，而是微分方程 \\(y'' = -ky\\) 的解就是 sin/cos。

纯正弦波只有一个频率，听起来像电子游戏里的"嘟——"声。真实乐器的声音由多个不同频率、不同振幅的正弦波叠加而成——这就是傅里叶变换的出发点。

频率 \\(f\\) 的国际单位是 Hz（赫兹） = s⁻¹ = 每秒振动次数。

3.1 八度与十二平均律

人耳感知音高的方式是对数关系：频率翻倍 → 听起来"高了一个八度"。

一个八度被平均分成 12 个半音，这就是十二平均律。设相邻半音的频率比为 \\(r\\)，则：

\[ r^{12} = 2 \quad\Rightarrow\quad r = \sqrt[12]{2} \approx 1.059463 \]

吉他每品就是一个半音。从空弦到 12 品正好一个八度（频率翻倍），到 24 品又翻倍。

3.2 MIDI 编号与频率的互推公式

国际标准：A4 = 440Hz，对应 MIDI 编号 69。任意 MIDI 编号 n 对应频率：

\[ f = 440 \cdot 2^{(n - 69) / 12} \]

推导：n 比 69 大 1 → 高一个半音 → 频率乘以 \\(2^{1/12}\\)。n 比 69 小 12 → 低一个八度 → 频率除以 2。\\(2^{(n-69)/12}\\) 精确表达了这种指数关系。

反过来，已知频率求 MIDI 编号（换算到最近的半音）：

\[ n = 69 + 12 \cdot \log_2\left(\frac{f}{440}\right) \]

例子：测到 100Hz，计算 \\(n = 69 + 12 \cdot \log_2(100/440) = 69 + 12 \cdot (-2.137) = 43.36 \approx 43\\)。MIDI 43 = G2 (98Hz)。确实最接近 G2。

4. 泛音：一根弦为什么发出多个频率

两端固定的弦（吉他弦正是如此），它的振动方程决定了它只能以整数倍基频的频率振动：

\[ f_n = n \cdot f_1 \quad (n = 1, 2, 3, \ldots) \]

其中 \\(f_1\\) 叫基频，决定音高。\\(f_2, f_3, \ldots\\) 叫泛音（谐波），各自以不同振幅叠加在基频上，共同决定音色。

交互：叠加谐波 + 实时音效

纯净正弦波。听听——电子游戏音效？

核心理解：真实声音 = 基频 + 泛音₁ + 泛音₂ + 泛音₃ + ……。频谱图上每根柱子对应一个泛音。最低最强的是基频，其余是泛音。吉他、钢琴、小提琴弹同一个 A4，基频相同，泛音比例不同 → 音色不同。

5. 时域与频域：两种"看"声音的方式

交互：左边时域、右边频域 + 音效

基频: 110 Hz

同一段声音，两种视角：时域 = 看波形随时间怎么变（波形图），频域 = 看每个频率各有多少能量（频谱图）。

傅里叶变换做的事情就是把左边的时域波形，变成右边的频域频谱。下面深入讲解它是怎么做到的。

6. 傅里叶变换——深度数学讲解

6.1 核心思想

任何周期信号都可以表示为若干个正弦波的加权和。傅里叶变换就是找到这些正弦波的频率和权重。

6.2 先理解"信号 × 标准波，再求和"

假设你有一段信号 \\(x[n]\\)（n 是采样点编号），你想知道"里面有没有频率 k 的成分"。怎么办？

想法：生成一个标准频率 k 的正弦波 \\(\sin(2\pi k n / N)\\)，然后把信号和它逐点相乘再累加：

\[ \text{分数}(k) = \sum_{n=0}^{N-1} x[n] \cdot \sin\left(\frac{2\pi k n}{N}\right) \]

为什么这能行？

  • 如果 \\(x[n]\\) 恰好包含频率 k → 信号和标准波同频 → 波峰对波峰、波谷对波谷 → 乘积大部分为正 → 总和很大。
  • 如果 \\(x[n]\\) 不包含频率 k → 信号和标准波不同频 → 时正时负 → 乘积正负抵消 → 总和 ≈ 0。

上面的演示中，最下方那条绿红相间的条就是乘积。绿 = 正，红 = 负。检测频率匹配时绿占主导，总和很大。

交互：乘法检测法 + 音效

检测频率: 110 Hz

6.3 一个问题：相位怎么办？

上面的做法有一个致命缺陷。如果信号里有频率 k，但相位恰好差了 90°（一个波在波峰时另一个在零点），乘积累加结果也是 0！

解决方案：同时用正弦 \\(\sin\\) 和余弦 \\(\cos\\) 去试探。因为 \\(\cos\\) 正好比 \\(\sin\\) 领先 90°，两者至少有一个能对上相位。这就像用两个"探测器"从不同角度去探测，保证不会漏掉。

6.4 正式公式：离散傅里叶变换 (DFT)

\[ X[k] = \sum_{n=0}^{N-1} x[n] \cdot e^{-i \cdot 2\pi k n / N}, \quad k = 0, 1, \ldots, N-1 \]

这个公式是整篇文章最重要的公式。逐项拆解：

\\(X[k]\\)输出频率 k 的"含量"，是个复数。|X[k]| = 幅度（频谱图柱子的高度），∠X[k] = 相位
\\(x[n]\\)输入第 n 个采样点的值（麦克风采到的气压值）
\\(N\\)点数一共 N 个采样点。调音器用 2048
\\(k\\)频率索引k=0 是直流分量，k=1 是基频 = 采样率/N，k=N/2 是奈奎斯特频率
\\(e^{-i \cdot 2\pi k n / N}\\)标准波这是整个公式的"心脏"，下面重点解释

6.5 \\(e^{-i\theta}\\) 到底是什么？——欧拉公式

高中数学没学过复数指数，但有一个最重要的公式需要知道：

\[ e^{i\theta} = \cos\theta + i \cdot \sin\theta \qquad \text{（欧拉公式）} \]

这意味着 \\(e^{i\theta}\\) 不是"一个"波，而是同时包含了 cos 和 sin，用一个复数打包。实部是 cos 分量，虚部是 sin 分量。

所以 DFT 公式展开后等价于：

\[ X[k] = \underbrace{\sum x[n] \cdot \cos\left(\frac{2\pi k n}{N}\right)}_{\text{实部（cos 试探器结果）}} \;-\; i \cdot \underbrace{\sum x[n] \cdot \sin\left(\frac{2\pi k n}{N}\right)}_{\text{虚部（sin 试探器结果）}} \]

两个试探器同时工作，保证无论相位如何都能检测到。最后 \\(|X[k]| = \sqrt{实部^2 + 虚部^2}\\) 就是频率 k 的幅度（频谱图上的柱子高度）。

6.6 手工算一个例子

假设 N=4，信号是 \\(x = [1, 0, -1, 0]\\)（这恰好是一个频率 k=1 的余弦波，周期为 4 个点）：

算 k=0（直流分量）：

\[ X[0] = 1\cdot e^0 + 0\cdot e^0 + (-1)\cdot e^0 + 0\cdot e^0 = 0 \]

信号对称，直流为 0 ✓

算 k=1（基频）：

\[ \begin{aligned} X[1] &= 1\cdot e^0 + 0\cdot e^{-i\pi/2} + (-1)\cdot e^{-i\pi} + 0\cdot e^{-i3\pi/2} \\ &= 1\cdot(1) + 0 + (-1)\cdot(-1) + 0 = 2 \end{aligned} \]

X[1]=2，非零！说明信号确实含有频率 1。k=2, k=3 继续算会发现都是 0——成功从信号中识别出它只包含频率 1。

小结：DFT 就是对 k=0,1,2,…,N−1 每个频率，分别用两个正交的"探测器"（cos 和 sin，打包在 \\(e^{-i2\pi kn/N}\\) 里）去试探信号，累加得到一个复数。复数的模 |X[k]| 就是频谱图上的柱子高度。

7. FFT 快速傅里叶变换——深度讲解

7.1 为什么需要 FFT？

DFT 直接算每一个 k 都需要 O(N) 次乘加，N 个 k 总共 O(N²)。N=2048 时约 419 万次——对于 60fps 的实时调音器来说太慢了。

FFT 不是近似算法，它精确地算出和 DFT 一模一样的结果，只是算得更聪明。

7.2 核心技巧：分治（Divide and Conquer）

FFT 的关键洞察来自 \\(e^{-i2\pi k n / N}\\) 的一个性质：

\[ e^{-i\cdot 2\pi k n / N} \quad\text{中，}\quad W_N = e^{-i\cdot 2\pi / N} \text{ 叫"旋转因子"} \]

\\(W_N\\) 有一个重要对称性：\\(W_N^{n+N/2} = -W_N^n\\)（旋转半圈 = 取反）。利用这一点，可以把 N 点 DFT 拆成两个 N/2 点 DFT：

\[ \begin{aligned} X[k] &= \sum_{n \text{ 为偶数}} x[n] \cdot W_N^{kn} + \sum_{n \text{ 为奇数}} x[n] \cdot W_N^{kn} \\ &= \underbrace{X_{\text{偶}}[k]}_{\text{偶数位置 DFT}} + W_N^k \cdot \underbrace{X_{\text{奇}}[k]}_{\text{奇数位置 DFT}} \end{aligned} \]

这意味着什么？算一个 N=8 的 DFT，拆成两个 N=4 的 DFT，再拆成四个 N=2 的 DFT……一直拆到底。

7.3 具体例子：N=8

原来要算 8×8=64 次乘法。FFT 的做法：

  • 第 1 层：8 点 → 2×4 点（2 个小 DFT + 组合）
  • 第 2 层：每个 4 点 → 2×2 点
  • 第 3 层：每个 2 点 → 2×1 点（1 点的 DFT 就是它自己）

总共 \\(\log_2 8 = 3\\) 层，每层约 N 次运算，总共 \\(N\log_2 N = 8 \times 3 = 24\\) 次——比 64 次快了一倍多。N 越大，优势越明显。

7.4 直观比喻：蝴蝶图

FFT 的数据流图形状像蝴蝶翅膀，所以叫"蝴蝶运算"（Butterfly）：

x[0] ──→ ──→ ──→ X[0]
x[4] ──→ ──→ ──→ X[1]
x[2] ──→ ──→ ──→ X[2]
x[6] ──→ ──→ ──→ X[3]
x[1] ──→ ──→ ──→ X[4]
x[5] ──→ ──→ ──→ X[5]
x[3] ──→ ──→ ──→ X[6]
x[7] ──→ ──→ ──→ X[7]

注意输入按"位反转"排列（000→000, 001→100, 010→010, …），输出按正常顺序

你不用实现 FFT。浏览器的 Web Audio API 已经内置了高度优化的 FFT（甚至可能用上了 SIMD 指令集），调用 getByteFrequencyData() 几十微秒就出结果。

7.5 FFT 在调音器中的角色

调音器把 FFT 的结果直接画成频谱图（频域柱状图），让你看到泛音分布。但测基频不靠 FFT——因为 FFT 分辨率太粗（2048 点 @ 44100Hz 每 bin 宽 21.5Hz），82Hz 和 104Hz 可能落在同一个 bin 里。基频检测用下面要讲的自相关算法。

8. 自相关算法——深度讲解

8.1 问题：给定一段波形，怎么精确知道它的周期？

假设采样率 44100Hz。如果一个信号周期正好占 200 个采样点，那么它的频率 = 44100/200 = 220.5Hz（接近 A3）。问题是如何从波形里自动找到 200 这个数字。

8.2 自相关的直觉

把波形复制一份，往后挪 k 个采样点，和原波形逐点对比。当 k 恰好等于一个完整周期的采样点数时，两个波形完美重叠。其他 k 值都对不齐。

交互：自相关可视化 + 音效

延迟: 20 采样点 | 对应 2205 Hz

8.3 怎么量化"对齐"？——皮尔逊相关系数

高中数学里学过相关系数来衡量两组数据的线性相关程度。两列数据 X 和 Y 的皮尔逊相关系数：

\[ r_{XY} = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum (x_i - \bar{x})^2 \cdot \sum (y_i - \bar{y})^2}} \]

其中 \\(\bar{x}, \bar{y}\\) 是各自的均值。r = 1 表示完全正相关，r = 0 表示无关，r = −1 表示完全负相关。

应用到信号上：Y = X 延迟 k 点后（先减去各自的直流分量）。去掉均值的项后得到归一化自相关：

\[ r(k) = \frac{\sum\limits_{i=0}^{N-1-k} x[i] \cdot x[i+k]}{\sqrt{\sum\limits_{i=0}^{N-1-k} x[i]^2 \cdot \sum\limits_{i=0}^{N-1-k} x[i+k]^2}} \]

逐项解释：

分子 \\(\sum x[i] \cdot x[i+k]\\)信号和它的延迟版逐点相乘再求和。对齐时乘积大，不对齐时正负抵消
分母 \\(\sqrt{\sum x[i]^2 \cdot \sum x[i+k]^2}\\)归一化因子。不管信号多强多弱，结果始终在 [−1, 1] 之间
k 的范围从 min（对应最高可检测频率）到 max（最低可检测频率）

8.4 抛物线插值：亚采样点精度

直接找最大 r(k) 只能精确到整数采样点。比如 k=200 点，频率 = 44100/200 = 220.50Hz。但实际频率可能是 220.63Hz（对应 k≈199.88）。

解：找到最大的 r(k) 后，取它左右两个点 (k−1, r(k−1))、(k, r(k))、(k+1, r(k+1))，用抛物线插值求真正的峰顶位置：

\[ k_{\text{精确}} = k + \frac{r(k-1) - r(k+1)}{2 \cdot (r(k-1) - 2r(k) + r(k+1))} \]

这个公式是二次函数顶点公式的变形。穿过三点拟合一条抛物线 y = ax²+bx+c，顶点横坐标就是上面这个式子。这样可以得到小数采样点，精度远超 FFT 的整数 bin。

为什么自相关比 FFT 更精确？FFT 分辨率 = 采样率/N = 44100/2048 ≈ 21.5Hz。自相关 + 抛物线插值精度 ≈ 采样率/(N×精细度) ≪ 1Hz。调音需要 1Hz 以下的精度，所以用自相关。

9. 音分（Cents）——深度讲解

9.1 为什么需要对数单位？

检测到频率 f=83Hz，目标 E2=82.41Hz。偏差 = +0.59Hz。同样偏差 +0.59Hz 如果发生在 330Hz 的 E4 弦上，人耳几乎听不到任何差别。

原因：人耳感知音高是对数关系。不是"增加 X Hz"听感相同，而是"乘以某个比例"听感相同。82→83 是 ×1.007，330→334.5 才是同样的感知偏差。

9.2 音分的定义与推导

定义：一个八度 = 1200 音分。一个半音 = 100 音分。

设 \\(f_1, f_2\\) 是两个频率，它们之间的音分差：

\[ \text{cents} = 1200 \cdot \log_2\left(\frac{f_1}{f_2}\right) \]

推导过程：

  1. 设 \\(f_2 = f_1 \cdot 2^{c/1200}\\)，其中 c 就是音分数
  2. 两边除以 \\(f_1\\)：\\(2^{c/1200} = f_2 / f_1\\)
  3. 两边取 \\(\log_2\\)：\\(c/1200 = \log_2(f_2 / f_1)\\)
  4. 乘 1200：\\(c = 1200 \cdot \log_2(f_2 / f_1)\\) ✓

9.3 验证：半音确实是 100 音分

一个半音频率比 = \\(\sqrt[12]{2}\\)。代入公式：

\[ c = 1200 \cdot \log_2(\sqrt[12]{2}) = 1200 \cdot \frac{1}{12} = 100 \]

✓ 一致。
